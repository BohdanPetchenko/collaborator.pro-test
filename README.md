# Тестове завдання: Frontend-розробник

Невеликий застосунок на React 19 + webpack 5: заголовок, картка з дропдауном, опис і кнопка.

- Умови завдання: [TASK.md](TASK.md)
- Звіт про виконання (виправлені баги, компроміси, пропозиції): [REPORT.md](REPORT.md)

## Запуск

Потрібен Node.js 18+.

```bash
npm install
npm start      # dev-сервер на http://localhost:8080
npm run build  # продакшн-збірка в dist/
```

## Стек

- React 19 (функціональні компоненти, хуки, автоматичний JSX runtime)
- webpack 5 + Babel (`@babel/preset-env`, `@babel/preset-react`)
- Звичайний CSS з нативним вкладенням (`&`), без препроцесорів

## Структура

```
src/
├── index.html                  # HTML-шаблон з контейнером #app
├── index.jsx                   # точка входу: стилі + монтування App
├── App.jsx                     # кореневий компонент: заголовок і картка
├── Dropdown.jsx                # випадний список (закриття по Escape і кліку поза ним)
├── assets/
│   └── DropdownArrowIcon.jsx   # SVG-стрілка дропдауна
├── greeting.js                 # утиліта для тексту привітання
└── styles.css                  # глобальні стилі
```
